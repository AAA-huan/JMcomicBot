# 🔧 命令大全

> - 群聊中发送命令前请先 @机器人；私聊可直接发送。
> - 命令与参数之间需要有空格，例如 `漫画下载 350234`。
> - 批量命令的多个 ID 用中文或英文逗号分隔（`350234,350235` 或 `350234，350235`），不要使用空格或句号。

## 📥 下载

| 命令 | 说明 |
|------|------|
| `漫画下载 <漫画ID>` | 下载单个或多个漫画，例如 `漫画下载 350234,350235` |
| `漫画下载 -c [ID列表]` | 取消排队中的下载；不带 ID 表示取消全部 |

别名：下载、下载漫画。下载命令不支持 `--all`，需提供具体漫画 ID。

## 📤 发送

| 命令 | 说明 |
|------|------|
| `发送漫画 <漫画ID>` | 发送单个或多个已下载漫画 |
| `发送漫画 --all` | 发送全部已下载漫画 |
| `发送漫画 -c [ID列表]` | 取消发送；不带 ID 表示取消全部 |

别名：发送、漫画发送。

## 🔍 查询

| 命令 | 说明 |
|------|------|
| `查询漫画 <漫画ID>` | 查询单个或多个漫画是否已下载 |
| `查询漫画 --all` | 查询全部已下载漫画 |
| `查询漫画 -t <标签>` | 按标签查询，例如 `查询漫画 -t 纯爱` |
| `查询漫画 -t <标签1,标签2>` | 多标签联合查询，取交集 |
| `查询漫画 -z <作者>` | 按作者查询，例如 `查询漫画 -z 作者名` |

别名：查询、漫画查询。

## 📚 漫画列表

| 命令 | 说明 |
|------|------|
| `漫画列表` | 查看概览（漫画数、PDF 数、总大小） |
| `漫画列表 -a` | 列出全部条目（也可用 `--all`） |
| `漫画列表 -2` | 查看指定页码，例如第 2 页 |

别名：列表、列表漫画。

## 🗑️ 删除（仅限配置的删除权限用户）

| 命令 | 说明 |
|------|------|
| `删除漫画 <漫画ID>` | 删除单个或多个已下载漫画 |
| `删除漫画 --all` | 删除全部已下载漫画 |

别名：删除、漫画删除。删除命令需要在「删除权限用户」名单内，否则会提示无权限。

## 📊 状态与版本

| 命令 | 说明 |
|------|------|
| `下载进度` | 查看下载队列状况 |
| `发送进度` | 查看发送队列状况 |
| `漫画版本` | 查看机器人版本信息 |

别名：`下载进度` 也可用 进度、漫画进度；`漫画版本` 也可用 版本、`version`。

## 🔧 其他

| 命令 | 说明 |
|------|------|
| `漫画帮助` | 显示帮助信息（别名：帮助、帮助漫画） |
| `重发重发` | 断线后确认重发未送达的漫画文件 |
| `测试id` | 查看机器人的 QQ 号 |
| `测试文件` | 发送测试文件，验证文件通道是否正常 |
| `你好` / `hi` / `hello` / `在吗` | 打招呼 |
| `我坐好了` | 彩蛋 |

## 📌 参数规则速查

- **批量命令**：下载、发送、查询、删除支持逗号分隔的多个 ID；
- **`--all` 支持**：发送 ✅、查询 ✅、删除 ✅、下载 ❌（下载需提供具体 ID）；
- **`-c` 取消**：仅下载与发送支持，且只取消尚未开始的任务；
- **无参数命令**：漫画帮助、漫画版本、下载进度、发送进度、测试id、测试文件、重发重发、我坐好了——附加参数会提示格式错误；
- **群聊限制**：群聊消息必须 @机器人 才会响应；删除命令仅限删除权限用户。
