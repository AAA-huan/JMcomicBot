# 🌐 WebUI 控制台（可选）

机器人内置单管理员 Web 控制台，可在手机或电脑浏览器中浏览漫画库、按 ID 下载漫画并查看实时进度、在线阅读 PDF、管理任务、维护权限与配置、执行扫描 / 修复 / 备份。默认只监听本机回环地址；任务、队列与下载进度通过 WebSocket 实时刷新。前端构建产物随项目发布，生产环境无需安装 Node.js。

## 访问与首次设置

1. 启动机器人，日志出现 `server WebUI 已启动: http://127.0.0.1:7999`；
2. 在**运行机器人的这台设备的浏览器**中打开该地址；
3. 首次访问会进入「首次设置」页，创建管理员密码（至少 6 个字符）。初始化只允许来自本机（127.0.0.1）的请求；
4. 之后使用该密码登录。页面包括：仪表盘、漫画库、漫画下载、JM 收藏导入、任务管理、权限管理、配置、文档、维护、操作审计。

## 修改密码、审计与文件校验

- 点击右上角「账户菜单」→「修改密码」，填写旧密码、新密码与确认密码。成功后所有设备的登录会话失效，使用新密码重新登录。
- 「操作审计」按事件类型和来源筛选，支持分页；筛选条件保存在地址中，刷新后可恢复。只展示操作摘要，不返回内部元数据或原始请求内容。
- 在「维护」的「校验 PDF 文件」中输入漫画 ID，单次最多 100 个，检查登记路径、存在性、大小、修改时间和 SHA-256。正在下载或发送的漫画暂不可校验。校验结果与进度持久化到任务列表，离开页面后仍可查看。
- 漫画删除只操作数据库登记的文件，支持改名和子目录 PDF；文件已丢失时清理漫画记录及关联阅读进度，同 ID 前缀的未登记文件不受影响。

## 数据导出与导入

维护页的「数据导出与导入」用于跨设备迁移漫画数据库：

- 「导出数据」会在线生成一致性整库快照，与 `export.json` 一起打包为 `data-export-{时间}-schema{版本}.zip` 下载。导出不会中断机器人，并记录 `data.exported` 审计。
- 「导入数据」选择导出的 zip 后先校验结构、SHA-256、数据库可读性与 schema 兼容性，再展示 schema 版本、各表行数与路径差异预览。确认后使用同一文件重新校验并替换整库，机器人随即重启。
- 导入会先关闭数据库连接，并把当前 `main.db` 及 `-wal`/`-shm` 备份为 `main.db.pre-import-{时间}.bak` 等文件。替换过程异常会自动恢复旧库；替换成功后若重启失败，需手动用该备份回滚。
- 只迁移数据库。PDF 文件需自行拷贝到当前 `MANGA_DOWNLOAD_PATH`；`.env` 中的启动配置（`NAPCAT_WS_URL`、`MANGA_DOWNLOAD_PATH`、`DB_PATH` 等）不会迁移，导入方需自行保持一致。`setting` 表运行时配置与 `permission` 表权限名单随数据库迁移。
- 导入确认会替换当前全部数据库，不可在线撤销。并发备份、导出或导入时，新的导入请求会被拒绝。

## 漫画下载与实时进度

- 在「漫画下载」页输入一个或多个漫画 ID，支持逗号、句号、分号、换行或空格分隔，单次最多 100 个。提交后页面提示已入队数量与已有活动任务的漫画 ID；重复请求不会创建重复任务。
- 下载开始后，页面实时显示「本子-JM编号」的章节总进度、每章图片进度与已耗时。图片级进度约每 0.5 秒合并推送一次，章节完成与整本结束立即刷新，不会对浏览器造成高频压力。
- 刷新页面或 WebSocket 重连后会重新读取服务端快照，继续显示当前或最近一次下载；下载完成后保留「下载完成」状态，直到刷新或下一个下载任务开始。页面只展示当前下载，排队任务请前往「任务管理」查看。
- 本页不提供队列概况，也不会补发 QQ 消息；低占用模式与失败重试行为仍与任务管理一致。

## 任务管理与重启续传

- 「任务管理」展示下载等后台任务的排队、运行与历史状态；仅带漫画 ID 的任务可勾选，支持全选、复制 ID、批量取消（排队任务）与批量重试（失败/中断任务）。
- 服务重启后，数据库中遗留的排队下载任务会直接重新入队；上次运行中的下载任务先标记为「已中断」并保留中断事件，随后复用原任务记录重新排队，任务 ID 不变。「取消全部排队」同样可以取消恢复中的任务。
- 恢复任务完成后只更新任务状态与审计，不会补发 QQ 消息；需要 PDF 时可在漫画库或漫画详情页手动发送。发送队列不落库，重启前尚未发送完成的文件不会自动重发。低内存模式下恢复下载等同于重新下载，完成后仍按低内存策略删除文件。

## 在线阅读与阅读进度

- 在漫画详情页的文件列表点击「阅读 / 继续阅读」进入在线阅读器（独立全屏页面）。
- 阅读器支持单页与连续滚动、适应宽度 / 适应页面 / 百分比缩放、页码跳转、全屏与深色背景；手机可左右滑动翻页。
- PDF 通过范围请求（Range）按需加载，只渲染当前页及相邻页并释放离开窗口的页面，不会一次加载整本漫画。
- 阅读进度保存在服务器，重新打开时自动恢复；翻页后约 1 秒自动同步，页面切到后台或离开时尽力立即保存。若工具栏提示「进度未同步」，可点击重试，不影响继续阅读。
- 文件列表中的下载按钮仍可将 PDF 保存到本地。

## 局域网 / 手机访问

默认仅本机可访问。需要在手机或其他设备访问时：

1. 编辑 `.env`，设置 `WEBUI_HOST=0.0.0.0` 与 `WEBUI_PORT=7999`；
2. 重启机器人；
3. 手机与电脑处于同一网络后，浏览器访问 `http://电脑IP:7999`；
4. 如系统启用了防火墙，需放行对应端口（例如 `sudo ufw allow 7999/tcp`）。

> 安全提示：局域网模式务必使用强密码并妥善保管；如需跨公网访问，请通过 HTTPS 反向代理（Caddy/Nginx）并限制为可信设备。

## WebUI 相关环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `WEBUI_ENABLED` | 是否启用 WebUI | `true` |
| `WEBUI_HOST` | 监听地址（`127.0.0.1` 仅本机，`0.0.0.0` 局域网） | `127.0.0.1` |
| `WEBUI_PORT` | 监听端口 | `7999` |
| `WEBUI_SESSION_HOURS` | 登录会话有效期（小时） | `24` |
| `WEBUI_DEV_ORIGINS` | 仅前端开发联调使用，生产留空 | 空 |

## 忘记密码（受控恢复）

WebUI 不提供在线重置密码入口。忘记密码时，请在**运行机器人的主机**上执行：

```bash
# 1. 停止机器人（Ctrl+C）
# 2. 清除管理员与会话记录
uv run python scripts/reset_web_admin.py --yes
# 3. 重新启动机器人，用本机浏览器访问 WebUI 重新完成首次设置
uv run python main.py
```

该脚本只删除 `web_admin` 与 `web_session` 表中的记录，不会影响漫画数据、下载文件与 QQ 功能。

### 启动配置编辑

配置页支持修改全部运行配置，包括低内存模式、漫画黑名单与删除绑定、下载/数据库/备份目录、SQL 日志开关（`DB_ECHO`）、WebUI 启用状态、监听地址、端口、会话有效期、开发环境额外来源（`WEBUI_DEV_ORIGINS`）和 NapCat 连接配置。启动项保存到启动加载的 `.env`，显示"待重启"，重启机器人后生效。普通手动启动时，环境中显式导出的同名变量仍优先于 `.env`；通过 WebUI 一键重启时，程序会先移除 `.env` 中同名配置键的继承环境变量，确保新进程读取 `.env` 的最新值，设置页也会标记被环境变量覆盖的启动项。读取 `.env` 时不会把其中的值写入进程环境变量，避免自重启时子进程继承旧值导致设置回退。从旧版本升级后，请先完整停止机器人并从终端重新启动一次，以清除旧进程已注入的环境变量；之后可从 WebUI 正常重启。局域网单管理员场景下敏感值明文显示，令牌留空可以清除。修改目录不会自动迁移数据库或漫画文件。即时生效配置继续由原有数据库与组件接口管理。

#### 下载器配置（option.yml）

配置页底部提供 option.yml 在线编辑器，保存后下一个下载任务即生效，无需重启。img2pdf 与进度插件由程序自动注入并覆盖关键项，编辑器只维护用户可见的下载参数（图片格式、并发数、下载目录等）。保存时校验 YAML 语法与顶层字典结构，非法内容返回中文错误提示。

### 漫画库操作

漫画库操作栏支持“全选 / 取消全选”当前页、复制选中 ID、批量删除、批量拉黑与批量解除；桌面表格表头复选框与操作栏按钮效果一致，移动端同样可通过操作栏全选当前页。分页或重新加载后会清空已有选择，避免误操作其他页数据。操作列的锁形按钮可对单条漫画加入黑名单或解除拉黑；“黑名单”分组展示当前拉黑列表，刷新页面会保留筛选。被拉黑的漫画即使从未下载，下载请求也会被跳过；默认不删除本地 PDF，开启“漫画黑名单与删除绑定”后才会与删除双向联动。

### 漫画收藏

在漫画库的漫画操作区点击星形“收藏”按钮，再次点击“取消收藏”可移除。桌面与手机均可使用。“收藏”分组可以与搜索、标签、状态和排序组合，刷新页面会恢复筛选。收藏属于当前 WebUI 管理员账户，重启保持；管理员关联 QQ 的变化不影响收藏。管理员收藏的漫画不能删除，须由管理员先在 WebUI 取消收藏，再执行删除；QQ 和 WebUI 的单个、批量删除均遵守此规则。其他用户不能取消管理员收藏。低内存模式的启动清理与延迟清理也会保留管理员收藏的 PDF。允许删除时会清理其他归属的收藏，重新下载不会恢复原收藏。本阶段尚未提供 QQ 收藏命令。

### 管理员关联 QQ

权限管理页顶部可关联一个管理员 QQ，支持更换与解除。关联用户可绕过机器人私聊和群聊白名单，并获得漫画删除与拉黑权限，黑名单仍优先。关联即时生效，解绑立即撤销该关联授予的权限，原有黑白名单和单独删除权限不变。群聊仍须 @机器人，WebUI 仍通过管理员密码登录。关联 QQ 必须为 1–20 位正整数数字，不含前导零；黑名单用户须先移出黑名单才能关联。「删除与拉黑权限用户」名单同时控制漫画删除、拉黑与解除拉黑命令。

### JM 天堂账号收藏导入

在侧边栏进入「JM 收藏导入」，登录 JM 账号后选择全部或指定收藏夹。后台分页读取漫画编号、标题和收藏夹归属，导入列表不下载漫画图片。已有本地漫画关联管理员收藏，未下载漫画独立保存，可每次选择最多 100 本加入下载队列。详见 [JM 收藏导入使用说明](jm-favorites.md)。

JM 密码不保存，账号会话最长保持 30 分钟。退出控制台、修改控制台密码、到期或重启后需重新登录；已导入记录保留。中途导入失败会保留已完成页，重新导入自动去重。本地操作不修改站点收藏。

数据库在启动时自动升级到 `0025_jm_favorite_import`，增加独立的远端收藏与导入任务表，沿用迁移前备份，保留既有账户、会话、漫画、本地收藏和阅读进度。
