# JM 天堂账号收藏导入

在 WebUI 侧边栏选择 **JM 收藏导入**，可读取 JM 天堂账号内的漫画收藏并保存到本项目。导入收藏列表不下载漫画图片；下载需要另外选择漫画。

## 登录与导入

1. 先登录 WebUI 管理员账号，再进入 **JM 收藏导入**。
2. 输入 JM 天堂用户名和密码，点击 **登录并读取收藏夹**。
3. 选择 **全部收藏** 或一个、多个指定收藏夹，点击 **导入收藏列表**。
4. 在 **最近导入** 查看分页进度，以及新增、已有和本地关联数量。

选择全部收藏时，也会读取各自建收藏夹以保留漫画的收藏夹归属。同一本漫画属于多个收藏夹时，只累计一次漫画数量。重复导入更新标题和收藏夹关系，不产生重复记录，也不删除手工添加的本地收藏。

## 下载与阅读

- 本地已有漫画会关联到管理员收藏，仍按原有规则受到收藏删除保护。
- 未下载漫画保存在独立导入列表，不计入本地漫画库，不影响扫描、修复和本地页数。
- 勾选未下载漫画后点击 **下载所选**，每次最多 20 本。重复请求复用已有下载任务。
- 在 **下载任务** 页查看进度；下载完成后刷新导入列表，可点击 **查看漫画**。PDF 入库时自动关联管理员收藏。
- 本地文件已删除或状态异常的记录在导入列表显示为未下载，可重新请求下载。

取消本地收藏不会修改 JM 账号。若希望再次将它加入管理员收藏，可以重新导入对应收藏夹。导入采用单向添加、更新策略，不因站点取消收藏而自动删除之前的导入记录。

## 会话与失败处理

JM 登录会话仅绑定当前 WebUI 登录会话，最长保持 30 分钟，不超过 WebUI 会话有效期。密码不写入数据库、配置文件、日志或浏览器本地存储。账号 Cookie 仅在服务端内存中使用。

退出 JM 账号、退出 WebUI、修改 WebUI 密码、会话到期或服务重启后，需要重新登录。已导入列表保留，之后无需登录 JM 也可查询和选择下载。

导入任务串行执行。中途网络请求失败时，任务明确显示失败并保留已完成页；重新登录或重试导入会自动去重。账号退出或服务重启造成的任务中断同样保留已完成数据。

本功能使用 jmcomic 的独立 API 客户端，不共享机器人下载客户端的账号会话。目前使用 jmcomic 默认 API 网络配置。真实账号能否成功登录取决于站点响应和部署环境的网络连接；页面会显示脱敏错误类型，不返回包含凭据的原始站点响应。
