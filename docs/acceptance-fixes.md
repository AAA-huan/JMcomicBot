# WebUI 与数据库验收问题修复

修复分支：`fix/webui-database-acceptance`，从 `dev` 的 `f503a3c` 创建。

## 五项修复

1. **删除目标**：`MangaService` 改为只读取漫画关联的登记路径，并复用安全路径解析。改名、子目录 PDF 可以删除；未登记的同前缀文件保留；文件丢失时清理记录与关联阅读进度；越界符号链接在标记 deleting 前拒绝。下载、发送冲突检查和既有任务、审计流程保留。
2. **PDF 按需读取**：仅增加 PDF.js 的 `disableAutoFetch=true`、`disableStream=true`，保留现有 Worker、渲染窗口及阅读进度逻辑。E2E 使用约 5 MiB、20 页 PDF，确认首页 Range 请求总量小于 3 MiB，跳到未读取页面后产生新请求。
3. **质量门禁**：Worker 测试校验实际被阅读器引用的打包文件及 JavaScript MIME，允许打包扩展名变化。补齐文档与少量明确配置、处理局部静态误报；项目 Pylint 检查尺度及原因见 [开发质量检查](quality-checks.md)。未通过拆分现有完整业务流程来满足默认复杂度阈值。
4. **修改密码**：账户菜单增加修改密码入口，使用现有 API 校验旧密码，成功后清空表单、清理前端会话并跳转重新登录。补失败提示和手机、桌面 E2E。
5. **审计与校验入口**：增加 `/api/v1/audit-events` 与 `/audit` 页面，支持精确事件类型、来源和稳定分页，筛选保存在 URL。维护页增加最多 100 个漫画 ID 的 PDF 校验，复用 `VerifyService`、持久化任务、任务推送及审计；正在下载或发送的目标返回冲突。审计 API 只返回明确列出的摘要字段。
